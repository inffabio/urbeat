Como usar na loja

Boas praticas para deixar o painel sempre pronto durante o atendimento.

  • Deixe /app/dashboard aberto durante o expediente.
  • Ative o som de pedidos no topo do painel.
  • Se o navegador nao oferecer instalacao, use o atalho/favorito do proprio aparelho.
  • No desktop, trate o navegador como apoio e deixe a automação principal com o local-agent.

Preparado para impressora Bluetooth

O painel web segue pronto para a jornada nativa quando a loja precisar imprimir pedidos no Android.

Impressoras como a Mini Thermal Printer TC-163 usam Bluetooth classico. O navegador/PWA nao acessa esse tipo de conexao de forma confiavel; a impressao direta fica preparada para o app Android/Capacitor.
