Comece pela POS-58 com 58mm sem guilhotina. Android usa Bluetooth. iOS, Windows, Linux e macOS usam Wi-Fi como preferencial. No desktop, use local-agent quando ele estiver instalado se a loja precisar de automacao real; deixe o navegador apenas como fallback manual.
