# UrBeat V2 — versão organizada

Abra `index.html` no navegador para visualizar a página.

## Estrutura

- `index.html`: página completa, formatada e comentada por seção.
- `assets/images`: imagens que antes estavam incorporadas no HTML.
- `assets/icons`: 20 ícones SVG exportados do bundle original.
- `assets/README.md`: inventário dos recursos visuais.

## Alterações no menu

- “Testar 15 dias grátis” foi substituído por “Criar meu cardápio”.
- “Entrar” foi incluído à esquerda do botão principal.
- As mesmas ações aparecem no menu móvel.
