# Essa feature deve ser colocada no registro do vendedor. Ela ira mostrar o que deve conter na senha para ficar forte

## A cada atendimento na contrução da senha deve ficar verde a validação. Como em sistemas profissionais

> ✅ Validações

### Campo de E-mail cadastro de vendedor

- Campo não pode estar vazio
- Formato de e-mail válido (regex: /^[^\s@]+@[^\s@]+\.[^\s@]+$/)
- Exibir mensagem de erro inline abaixo do campo
- Campo de Nova Senha (Tela 3)
- Mínimo de 8 caracteres
- Pelo menos 1 letra maiúscula
- Pelo menos 1 letra minúscula
- Pelo menos 1 número
- Pelo menos 1 caractere especial (!@#$%^&*)
- Campo "Confirmar senha" deve ser idêntico ao campo "Nova senha"
